
## 要点（seed 0）

- **统一输入后优于 MultiHeadSTGCN、且差距超过 0.5% 噪声底线**：GWNET（-3.20%）、MTGNN（-0.85%）。
- **与 MultiHeadSTGCN 在噪声范围内持平**：AGCRN（-0.42%）。
- **日历特征有收益的模型**（同模型配对）：FNN -11.9%、STGCN -7.6%、AGCRN -5.3%、MTGNN -2.6%、GWNET -1.9%。
- **日历特征反而变差的模型**：GRU +10.2%、LSTM +18.4%。
  LibCity 的 RNN 不做空间建模，把 170 个节点 × 通道拼成一个向量输入（9 通道时为 1,530 维，隐藏层 64）；星期 one-hot 对所有节点相同，等于多出 1,190 维冗余输入。训练损失和验证损失从第一轮起都更高，属于默认超参（lr 0.01、多步衰减）下的优化困难，不是过拟合，也不能说明日历特征本身有害。
- 最佳验证轮次等于第 100 轮、仍未收敛：FNN、LSTM，加预算可能继续下降。

## 怎么读这张表

- 本表只控制**输入信息**。优化器、学习率、损失（MultiHeadSTGCN 的 `scale_aware_loss`）、多步策略（STGCN 单步滚动、MultiHeadSTGCN 直接多步、MTGNN 课程学习）仍按各模型默认，差异不能全部归因于网络结构。
- 噪声底线约 0.5%（同配置同种子重跑的 MAE 差）。以上各表只有 seed 0，小于 0.5% 的差异不作结论；前 4 名的多种子复核见下一节。
- 「变化」列是同一模型加日历特征前后的配对差，可直接说明日历特征对该模型的收益。
- 所有 mps 运行（含多种子）的原始数据哈希、节点顺序、scaler 和测试窗口顺序已逐一核对一致（脚本不一致时会拒绝生成）。

### 多种子结论

- **GWNET**：seed 0 显示更好（-3.20%）；5 个种子配对均值 -4.22%（95% CI -4.98% ~ -3.47%），5/5 个种子优于 MultiHeadSTGCN（符号检验双侧 p = 0.062）→ **仍然成立**。
- **MTGNN**：seed 0 显示更好（-0.85%）；5 个种子配对均值 -0.55%（95% CI -1.29% ~ +0.20%），5/5 个种子优于 MultiHeadSTGCN（符号检验双侧 p = 0.062）→ 方向一致但**不显著**，不能下“更好”的结论。
- **AGCRN**：seed 0 在噪声范围内持平（-0.42%）；5 个种子配对均值 +0.44%（95% CI -0.38% ~ +1.27%），1/5 个种子优于 MultiHeadSTGCN（符号检验双侧 p = 0.375）→ 仍为持平。
- **排名**：按均值为 GWNET < MTGNN < MultiHeadSTGCN < AGCRN（MAE 由低到高）。MultiHeadSTGCN 在各种子内的名次：seed 0 第 4、seed 1 第 3、seed 2 第 3、seed 3 第 3、seed 4 第 3。
- **种子间波动**：各模型 MAE 的标准差为均值的 0.29%–0.72%，可与 0.5% 的同种子重跑噪声底线对照。
- **最佳轮次接近 100 轮上限**：GWNET seed 2（93/100）、GWNET seed 4（98/100）、MTGNN seed 2（90/100）、MultiHeadSTGCN seed 3（91/100）。这些运行加预算可能还会下降，即这些模型的均值可能偏高。
- **设备差异**：MultiHeadSTGCN 全部使用 mps 运行；master 上 CUDA 记录（n=5）的均值为 14.8362，mps 均值 14.8256（-0.07%），仅作参考，不参与配对；同一 seed 0 在 CUDA 与 mps 上分别为 14.9018 / 14.8392（mps 相对 -0.42%）。
