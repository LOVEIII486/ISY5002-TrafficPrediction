# 任务 A：新加坡测试集人工标注

## 为什么要做

识别部分在公开数据集 MIO-TCD 上已经有人工真值的准确率（冻结测试集 mAP@0.5：官方预训练 0.43 → 微调 0.72），
但**在我们自己的新加坡摄像头上还没有真实准确率**：现在的新加坡「答案」是大模型 YOLO26x 自动画的（伪标签），
只能说明「和大模型像不像」。你的任务是把 80 张新加坡图的答案改成人工确认过的，得到第一个新加坡场景的真实测试集。
任务 B、C 的最终评估也要用它。

## 你会拿到

- 标注包 `lta_annotation_package.zip`（14 MB）：80 张图、Label Studio 任务文件、界面配置、图片服务脚本、标注规范、使用步骤；
- 不需要装项目代码，只要 Python 和 Label Studio。

## 步骤

1. 解压标注包，**先完整读一遍 `LTA_ANNOTATION_GUIDE.md`**（标注规范，10 分钟）；
2. 按 `README_annotation_package.md` 装好 Label Studio、导入任务（约 10 分钟）；
3. 按 `order` 顺序标注：
   - 每张图上已有大模型的框，**红框 `candidate` 每个都要处理**（是车改成 1–4 类，不是车删掉）；
   - **从左到右扫一遍，补上所有漏标的车**——这是整个任务最重要的一步，夜间排队车流和摩托车漏得最多；
   - 每张做完点 Submit；
4. **先完成前 40 张（batch A）**，每个相机 5 张、白天夜间都有。时间够再做后 40 张（batch B）；
5. Export → JSON，把文件发给负责人。

## 标注一致性检查（5 张）

80 张都由你来标。另外，负责人会**独立**再标 order 1–5 这 5 张，用来算两名标注者的一致性。
报告里能写「两名标注者在重叠样本上的一致性为 xx」，很加分。标完交付之前，不要和负责人对这 5 张的答案。

## 规则

- 图里有车牌，只在组内使用，不要上传到公开的地方；
- 拿不准的情况按规范里的表格处理，规范没写到的记下来，标完一起问，**保持前后一致比单张完美更重要**；
- 不要为了快只改已有的框不补漏标，那样测试集会偏向大模型，结论不可信。

## 交付物

1. Label Studio 导出的 JSON；
2. 你的名字、标了哪几张（order 范围）、大概用时；
3. 规范没覆盖、你自己做了决定的情况清单（几行字就行）。

## 时间

batch A 约 1–1.5 小时，全部 80 张约 2–3 小时。夜间长堤画面一张可能要补几十个框，最费时。

## 交付后

负责人运行 `python -m src.detection.annotate collect <你的 JSON> --annotator "<你的名字>"` 生成冻结测试集
`datasets/lta_human_v1/`，然后三个模型在上面各评估一次。报告里写成「教师模型预标注 + 人工逐张修正」，标注人署你的名字。
