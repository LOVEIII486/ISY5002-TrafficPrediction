# LTA 验证图人工修正规范

对象：week2 的 80 张 LTA 验证图（从未参与训练），工具 Label Studio 本地版，流程见 `src/detection/annotate.py`。
目标是得到**新加坡摄像头上的真实答案**，用来测模型的真实准确率。规范要前后一致，比单张图的完美更重要。

## 打开时你会看到

- 蓝 / 橙 / 绿 / 黄框：大模型（yolo26x）预先画好的 car / motorcycle / bus / truck；
- **红框 `candidate`**：大模型不太确定、原本被丢掉的框。实测多数是真车（远处小车、夜间车灯、摩托车）。
  **每个红框都必须处理**：是车就按 1–4 改成对应类别，不是车就删掉。留着红框导出会被拒收。

## 逐车检查（最重要）

大模型会漏标，尤其是远处小车、夜间排队车流和摩托车。**不要只改已有的框**，每张图都要从左到右扫一遍，
看到没框的车就补上。只改不补，测试集会偏向大模型的判断，对「学大模型」的联合训练模型有利，结论就不可信了。

## 标什么

| 情况 | 怎么做 |
|---|---|
| 路上能认出是车的 | 标，哪怕很小 |
| 被遮挡的车 | 能看到一半以上就标，框住**可见部分** |
| 路边停着的车、加油站里的车 | 标（画面里的车都算） |
| 行人、自行车 | 不标 |
| 夜间：能分出一对车灯或车身的 | 标，框住车灯和能看到的车身 |
| 夜间：一团分不开的光斑 | 不标（分不出几辆就不强行猜） |
| 画面边缘只露一小角 | 露出不到一半就不标 |
| 水面倒影、广告牌上的车 | 不标 |

## 类别

| 类别 | 包括 | 快捷键 |
|---|---|---|
| car | 轿车、SUV、出租车、MPV、面包车 / 厢式小货车（van） | 1 |
| motorcycle | 摩托车、电动摩托、踏板车，**框住车和骑手** | 2 |
| bus | 公交车、大巴、旅游巴士、校车、小巴 | 3 |
| truck | 货车、卡车、皮卡、拖头、工程车、集装箱车 | 4 |

皮卡归 truck、面包车归 car，与 MIO-TCD 的类别合并规则一致。远处太小分不清类别时，按最像的标；实在分不清就标 car。

## 框怎么画

- 贴紧车身外轮廓，不要留大片空白，也不要切掉车头车尾；
- 一辆车一个框，大货车的车头和挂车算**一辆**；
- 两辆车挨在一起时分开画，不要一个框框两辆。

## 节奏建议

- 按任务里的 `order` 顺序做。**前 40 张（batch A）每个相机 5 张、白天夜间都有**，先做完它就能单独用；
- 夜间排队的长堤画面最费时，一张可能要补几十个框，累了就先停，不要赶；
- 每张做完点 Submit，Label Studio 会自动保存。

## 标完之后

在 Label Studio 里 Export → JSON，然后：

```bash
python -m src.detection.annotate collect <导出的 JSON> --annotator "你的名字"
```

生成 `datasets/lta_human_v1/`（冻结，不覆盖），再用 `evaluate.py --data datasets/lta_human_v1 --split val` 评估。
报告里写成「教师模型预标注 + 人工逐张修正」，不要写成「从零人工标注」。
