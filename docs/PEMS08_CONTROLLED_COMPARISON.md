# PeMS08 统一输入对照方案

## 如何理解可比性与三个主要字段

不同架构可以采用各自的特征工程、固定路网或学习图，比较完整方法的性能。
输入通道数不同不意味着现有 benchmark 无效；统一输入实验用于进一步分析提升来源，
不必作为所有方法对比的前提。但同一数据集名称也不足够：还要核对预测目标、
时间划分、历史/预测窗口、测试时间点、指标以及推理时信息是否可获得。

PeMS08 的 `traffic_flow`、`traffic_occupancy`、`traffic_speed` 是三种主要交通测量字段。
数据文件含这三列，不代表每次训练自动使用三列。仓库原有记录中，flow、occupancy、speed
分别训练时只选择对应的一个测量字段（另可加入日历特征）；
`traffic_flow+traffic_occupancy+traffic_speed/.../seed0_joint-scaled` 才是三测量值输入、三目标输出。
本轮 8 模型重跑均设置 `data_col=[traffic_flow]`、`output_dim=1`，未使用占有率或速度作为交通输入。
星期是辅助特征，收益需消融验证；它与选择几个交通测量变量是两个独立设置。

若之后采用“过去三测量值预测未来流量”，应显式区分输入列和输出列。
当前 RNN/STGCN 的滚动预测会从 y 中取得额外通道；日历特征可提前知道，
但未来占有率和速度不可取得，不能直接把这两列当作日历外部通道接入，否则会泄漏未来测量值。

依据：[LibCity 基准论文 §5.3](https://arxiv.org/html/2308.12899#S5.SS3)。
论文统一公共评估条件、使用原论文模型参数，并明确采用 Adam；本仓库部分模型沿用 RMSprop，
故当前实验应表述为“仓库配置复现”，不能声称逐项严格复现论文。

## 为什么需要另一张表

当前 `aligned_20261013_mps` 是按新仓库各模型默认配置做复现，公共数据和评估协议一致，
但模型实际使用的信息不同：FNN/STGCN/GWNET/AGCRN 只有流量，GRU/LSTM/MTGNN
还有时刻，MultiHeadSTGCN 还有时刻与星期。默认配置表可以比较完整方法的效果，
不能据此声称网络结构本身带来全部提升。

## 成本最低的补充对照

所有模型都只使用过去 12 步的流量，预测未来 12 步流量，输入形状均为 `(B, 12, 170, 1)`。
保持同一份数据、节点顺序、7:1:2 划分、scaler、batch 64、最多 100 轮、早停 30、seed 0，
并使用相同的测试时间索引和指标定义。最终权重仍由验证集选择，不能按测试分数挑配置。

FNN、STGCN、GWNET、AGCRN 的当前实际输入已经符合这项条件，完成后可以复用本轮记录；
需检查数据指纹、测试索引与公共协议相同，再加入统一输入表。

另外四个模型补跑：

```bash
python -m src.forecast.run_benchmark \
  --dataset PEMSD8 --targets traffic_flow \
  --models GRU,LSTM,MTGNN,MultiHeadSTGCN --seeds 0 \
  --device mps --threads 4 --tag flowonly_20261013_mps \
  --set load_external=false \
  --set add_time_in_day=false \
  --set add_day_in_week=false
```

## 两张主表与一组消融

1. **默认配置表**：说明各方法按原设置的整体表现。标明输入通道、日历特征、路网信息、学习图及训练设置。
2. **统一流量输入表**：让所有模型接收相同的交通历史，检查默认表的优势是否依赖额外时间信息。
3. **时间特征配对消融**：对 GRU/LSTM/MTGNN/MultiHeadSTGCN 分别比较本轮配置与 flow-only。
   对 MultiHeadSTGCN 若需拆开时刻和星期收益，还应补“流量 + 时刻”这一项；本次尚未启动。

## 进一步论证结构贡献

- 学习率和优化器可以按模型选择，但应只用验证集调参、给予相同调参预算，并记录搜索范围。
  强行给所有模型固定一个学习率，也可能不公平。
- 比较 STGCN 与自定义模型的结构改动时，应把输入、损失与训练策略列为单独因素。
  当前 STGCN 使用 quick 单步训练，自定义模型直接多步训练，且后者单目标也默认启用
  `scale_aware_loss` 的按批次尺度加权。这些收益不能全部称为图结构收益。
- 为匹配的种子集合报告均值与标准差；单 seed 0 只能作为初步结果。
- 同时报告 15/30/60 分钟误差和 12 步平均，说明是否保留最后批次补齐样本。
- 图模型的固定路网与学习图属于方法设计的一部分，应标明；统一流量输入并不代表各模型对道路拓扑的使用方式相同。
