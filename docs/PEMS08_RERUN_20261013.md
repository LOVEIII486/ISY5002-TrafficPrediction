# PeMSD8 流量实验：各模型默认配置复现（2026-10-13）

状态：**completed**。已完成 8/8 个模型。

## 实验设置

使用新仓库锁定的 LibCity 版本 `5a6391d41944e937f2c15e9be85ab7f40ac8b23e`，交通流量单目标，170 个节点，5 分钟采样，12 步输入预测 12 步。窗口构造后按 7:1:2 划分，batch 64，最多 100 轮，早停耐心 30，seed 0。本轮设备：`mps`；原参考实验设备为 CUDA。

各模型保留其 LibCity 默认输入特征、优化器、学习率和调度器；MultiHeadSTGCN 使用新仓库的定型配置，MTGNN 使用 step_size1=627。这是按原仓库公共协议复现的对照，不是所有模型输入/优化器完全相同的结构消融。

数据来自已校验的 ASTGCN PeMS08 原始文件，转换为 PEMSD8；流量的 float32 转换无精度损失。原子格式全量数值核对与 FNN 测试目标时间对齐已通过，见 `dataset_verification.json`。历史参考实验没有原始数据文件/哈希，因此仍不能证明与其数据逐值一致。

## 对比范围与下一组受控实验

本轮比较的是各模型默认配置的整体表现。输入、优化器、训练损失和多步训练策略不同，不能把误差差异全部归因于网络结构。

| 模型 | 实际输入 |
|---|---|
| FNN / STGCN / GWNET / AGCRN | 流量，1 通道 |
| GRU / LSTM / MTGNN | 流量 + 时刻，2 通道 |
| MultiHeadSTGCN | 流量 + 时刻 + 星期，9 通道 |

建议补充一张统一流量输入的对照表：保持本轮数据、划分、窗口、batch、选模与指标，关闭所有外部/日历特征。现有 1 通道模型的结果可在数据指纹和协议一致时复用，只需补跑 GRU、LSTM、MTGNN、MultiHeadSTGCN 四项。再与本轮同模型做配对比较，衡量时间特征的收益。

统一输入只控制输入信息。若进一步声称结构贡献，应对照相同损失/训练策略，或为各模型提供相同的验证集调参预算，并增加匹配种子的重复实验。固定图与学习图的使用情况也应列明。

实施命令与比较口径见 [统一输入对照方案](PEMS08_CONTROLLED_COMPARISON.md)。该组补充实验尚未启动。
